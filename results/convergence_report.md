# DG Burgers convergence and error report

Problem: u_t + (u²/2)_x = 0 on [0, 2π), periodic, u0 = 0.5 + sin x, breaking time t_s = 1, shock forms at x = π + 0.5.

## Smooth regime: t = 0.5 t_s (no limiter, Godunov flux, SSP-RK3)

Reference: exact solution via characteristics (Newton/bisection to 1e-14). Norms use a (p+6)-point Gauss rule per cell; Linf also samples cell ends. For p ≥ 3, dt is reduced like h^((p+1)/3) so the 3rd-order time error does not hide the spatial order.

## Post-shock regime: t = 1.5 t_s (TVB minmod limiter, M = 5)

Reference: exact entropy solution (shock at x = π + 0.5t, jump [u] = 1.9944). With a captured discontinuity the full-domain L1 error is O(h) with a constant that depends on where the shock sits inside its cell, so pairwise orders fluctuate; L1/([u] h) staying bounded is the robust check.
